# Repository guidance

- Windows desktop app; Python 3.14 is the documented source environment. Install GUI deps with `python -m pip install -r requirements-gui.txt`; packaging adds pinned PyInstaller via `requirements-build.txt`.
- Main entrypoint is `epd_gui.py` (Tk GUI, `--offline` for no-device mode); device workflow is in `epd_writer.py`, image conversion in `image_codec.py`. The independent `research_cli.py` is not used by the GUI.
- Two transports share the verified PN532/ISO-DEP code: `wakeup_probe.Reader` for HSU serial ports and `acr122_reader.PcscPn532` for an ACR122U over USB PC/SC (`pyscard`). Device values are plain `COMx` strings or `acr122:<reader name>`; `epd_devices.py` enumerates and parses them. ACR122U writes require the one-time Windows `EscapeCommandEnable` registry value, set by `enable-acr122-escape.ps1` as administrator followed by a replug; never substitute ordinary PC/SC APDU framing for the display's 7-bit wake/ISO-DEP path.
- Run focused offline verification with `python verify_gui_offline.py`; run unit tests with `python -m unittest discover -v`. GUI checks need a desktop/Tk session. Tests use synthetic credentials and simulated transport; do not require real hardware. ACR122U tests inject a fake PC/SC link instead of opening a reader.
- Package with `python -m PyInstaller --noconfirm EInkTool.spec` (or `build-exe.ps1` to also copy `LICENSE`, `NOTICE` and `enable-acr122-escape.ps1`). Output is `dist/EInkTool.exe`; do not include personal config, logs, images, or refresh history in builds/commits.
- Hardware actions are explicit: only Detect/Write opens PN532 serial or ACR122U PC/SC communication. Avoid replaying application commands automatically; refresh/transport failures can leave device completion unconfirmed. Offline tests/self-test do not establish hardware compatibility; ACR122U antenna coupling and RF power are not guaranteed even when detection succeeds.
- User-specific `epd-device-config.json`, runtime settings/history, and logs are local data; preserve `.gitignore` exclusions and never replace or commit these files. The documented config PIN overrides the built-in default; malformed config disables writing rather than silently falling back.
- Preserve `LICENSE` and `NOTICE` when distributing source or executables; project code is PolyForm Noncommercial 1.0.0 licensed.
